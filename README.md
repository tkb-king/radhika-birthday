# Radhika's Birthday Website 🎂✨

A luxurious and elegant birthday celebration website for Radhika.

## 📋 How to Use

1. **View Online**: Open `index.html` in any web browser
2. **GitHub Pages**: Enable GitHub Pages in repository settings to share with everyone
3. **Share**: Send the link to celebrate Radhika's special day!

## ✨ Features

- ✅ Luxury elegant design with premium styling
- ✅ Beautiful photo gallery with her pictures
- ✅ Personalized birthday message
- ✅ Smooth animations and transitions
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Interactive elements with elegant hover effects
- ✅ Optimized performance

## 📁 Files

- `index.html` - Main page structure
- `styles.css` - Luxury styling and animations
- `script.js` - Interactive features
- `photos/` - Photo directory with Radhika's pictures
